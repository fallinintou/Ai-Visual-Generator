# AI Visual Generator

AI Visual Generator adalah aplikasi web berbasis PHP Native yang dirancang untuk membantu proses pembuatan aset visual event secara otomatis menggunakan Generative AI.

Melalui aplikasi ini, pengguna dapat memasukkan beberapa parameter seperti nama event, jenis visual, tema desain, unsur budaya lokal, unsur sains atau teknologi, dan warna dominan. Sistem kemudian akan membentuk prompt secara otomatis menggunakan pendekatan prompt engineering, lalu mengirimkan prompt tersebut ke Pollinations AI untuk menghasilkan gambar visual.

Project ini dibuat sebagai studi kasus integrasi aplikasi web konvensional dengan layanan Generative AI pihak ketiga. Selain itu, project ini juga menampilkan konsep dasar pengelolaan hasil generate, penyimpanan data ke database, gallery visual, detail prompt, quick preset, random idea, search/filter gallery, dan loading overlay saat proses generate berlangsung.

## Main Features

- Generate visual assets using AI
- Enhanced prompt engineering
- Pollinations AI integration
- Event logo, poster, banner, and studio portrait generation
- MySQL database storage
- Generated visual gallery
- Search and filter feature
- Quick preset and random idea button
- Loading overlay animation
- Modern glassmorphism UI
- PHP Native implementation
